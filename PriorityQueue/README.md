This directory serves as an execution ledger for problems solved using the Priority Queue pattern.

> **Complexity Rule:** Time and Space complexity must be stated before coding.

Kth Largest Element in an Array](https://leetcode.com/problems/kth-largest-element-in-an-array/) | 5m logic<br> 15m total | **Pattern:** MinHeap <br>**Trigger:** "Kth Largest Element" | **Time:** `O(n*log(k))`<br>**Space:** `O(k)` | Use a minHeap to store the largest k elements. Every time you poll a node, add the next node in that list back into the minHeap if it exists | If you have no lists, return an empty list |

Instead of a `dist[]` array, maintain a `dist[][]` i.e. distance per node per stop. <br> BFS/Bellman-Ford approach : Explore the graph level-by-level and update the min distance to each node at each level, stop at k+1 level, or relax the edges k+1 times. | For a single node graph the cost is 0 |
