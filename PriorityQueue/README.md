Kth Largest Element in an Array](https://leetcode.com/problems/kth-largest-element-in-an-array/) | 5m logic<br> 15m total | **Pattern:** MinHeap <br>**Trigger:** "Kth Largest Element" | **Time:** `O(n*logk)`<br>**Space:** `O(k)` | Use a minHeap to store the largest k elements. At the end, if the resultant path as n nodes then you can complete all courses else not | For a single course, you can always complete the course |
